# Waveshare 3.5inch DSI LCD (H)

Комплект для проверки дисплея Waveshare **SKU 33087** на Radxa Dragon Q6A через J10 и шлейф AC005.
На Q6A с ядром `7.0.11-7-qcom` Goodix GT911 передаёт события касания в `evtest`.
Панель выводит 480×800 при 60 Гц, но изображение мерцает во всех трёх проверенных режимах DSI.
Причина мерцания и поведение после холодного старта остаются открытыми.

Скопируйте содержимое [каталога для Q6A](target/sbc/radxa_dragon_q6a/) в `~/waveshare-35h` на плате и выполните:

```sh
sudo python3 ~/waveshare-35h/install.py
```

В меню embloader появится отдельная запись **Waveshare 35H (auto)**.
Для возврата выберите прежнюю запись. Один оверлей описывает панель, питание и сенсор.
Параметры `--sync-pulse` и `--burst` добавляют пробные записи с другими режимами передачи.
