# Radxa Dragon Q6A

Скопируйте этот каталог целиком на Q6A и запустите из него `sudo python3 install.py`.
Для пробной загрузки выберите **Waveshare 35H (auto)** в embloader. Параметр `--entry` позволяет явно указать исходную загрузочную запись.
